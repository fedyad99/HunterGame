# Охотники на колёсах

Кооперативный (1–4 игрока) симулятор охоты и выживания на **Godot 4.3** (GDScript).
Компания охотников путешествует на доме на колёсах по холмистому открытому миру,
охотится, разделывает и продаёт туши, следит за едой, водой, теплом, сыростью
и туалетом. Физика нарочно немного смешная: персонажи падают, туши болтаются в руках,
с крыши дома можно вылететь.

## Как запустить

1. Установите [Godot 4.3](https://godotengine.org/download) (стандартная версия, не .NET).
2. Откройте папку проекта в Godot (Import → `project.godot`) и нажмите F5.
3. В меню нажмите **«Создать игру (хост)»**. Друзья вводят IP хоста и жмут **«Подключиться»**.

### Игра по сети

Выделенного сервера нет: мир живёт у хоста, остальные подключаются к нему (ENet, UDP, порт 7777).

- **Локальная сеть:** IP хоста из `ipconfig`.
- **Интернет:** пробросить UDP-порт 7777 на роутере хоста, либо всем установить
  Radmin VPN / ZeroTier / Hamachi и подключаться по их IP.
- **Steam (позже):** сетевой код использует высокоуровневый `multiplayer` API Godot,
  поэтому вместо ENet можно подставить `SteamMultiplayerPeer` из GodotSteam
  (бесплатно, для тестов есть AppID 480). Своя страница в Steam стоит $100 (Steam Direct).

## Управление (F1 в игре)

| Клавиша | Действие |
|---|---|
| WASD, Shift, Пробел | ходьба, бег, прыжок |
| Мышь, ПКМ, ЛКМ | камера через плечо, вскинуть оружие и прицелиться, выстрел или бросок предмета из рук |
| R, T, 1–4, колесо | перезарядка, тип патрона (дробь или пуля), выбор оружия |
| E | взаимодействие: взять, сесть, разделать, жарить, магазин, кнопки в кабине, трос лебёдки |
| P | туалет (где угодно) |
| Q | положить предмет из рук |
| Tab | рюкзак: есть, пить, курить, бинт, выбросить |
| X / Z | меню эмоций / плюхнуться |
| L, H | фонарик, гудок |
| **За рулём:** W, S, A/D | газ, тормоз, руль |
| Shift / Ctrl | передача вверх / вниз (механика R-N-1-2-3-4-5) |
| V | вид из кабины / снаружи |
| F / G | мотор лебёдки спереди / сзади (или кнопки на панели через E) |
| Esc | пауза, настройки (клавиши, мышь, графика, звук) |

Все клавиши переназначаются в **Настройках**.

## Что есть в прототипе

- **Мир:** процедурный холмистый рельеф 800×800 м с озёрами, дорогами, ельником и березняком,
  трава с ветром, 4 фактории (магазин, приёмка дичи, колонка, костёр, разделочный стол).
  Смена дня и ночи, дождь, температура.
- **Персонаж:** вид от 3-го лица, процедурные анимации, эмоции (помахать, танец, смех и др.),
  рэгдолл-падения (с высоты, под колёсами дома, от удара кабана, по кнопке).
- **Потребности:** сытость, вода, «по-маленькому» и «по-большому» (кусты или туалет в доме,
  разные анимации), тепло, сырость. Мокрая одежда греет хуже. Сушиться можно у костра
  или у печки в доме (улучшение). Есть куртка и дождевик. Курение (анимация затяжки, дым)
  и алкоголь (экран плывёт, персонажа шатает). Кровотечение, бинты, смерть с
  возрождением у дома (команда теряет 15% денег).
- **Рюкзак:** 8 ячеек с иконками предметов и до 30 кг, оружие тоже занимает ячейки. Крупное (туши, канистра) носится в руках и замедляет.
- **Охота:**
  - баллистика у хоста: скорость пули, падение, сопротивление воздуха;
  - 5 типов патронов с разным пробитием и 4 ружья;
  - зоны поражения: мозг, сердце, лёгкие, голова, мышцы, ноги;
  - звери умирают от кровопотери и оставляют кровавый след;
  - мелкий калибр не пробивает кабана и медведя, крупный превращает зайца в ничто
    (туша повреждена или уничтожена);
  - заяц, олень, кабан (атакует), медведь (атакует).
- **Туши:** их можно переносить с физикой, разделывать на мясо и шкуры, жарить (иногда мясо
  подгорает) и продавать через ящик приёмки или из рюкзака. Деньги общие на команду.
- **Дом на колёсах:**
  - в него физически заходят: ступеньки, правая дверь, салон со столом, диваном, кроватью, плитой и шкафом-сушилкой, лестница на крышу;
  - тяжёлый, на мягкой подвеске, в пути качается; всё, что внутри (и вы сами), болтает на разгоне и торможении;
  - за руль садятся по E на кресле, вид из кабины (V — вид снаружи); скорость, обороты, передача, бензин и поломки — на приборной панели;
  - кнопки на панели (смотрите на них и жмите E): лебёдка спереди, лебёдка сзади, фары, гудок;
  - лебёдка ручная: взять трос у крюка, донести до дерева или камня (до 30 м), зацепить, включить мотор кнопкой;
  - механическая КПП, плавные обороты с мягкой отсечкой, сцепление зависит от поверхности;
  - боковые зеркала с живым отражением;
  - 4 сиденья: водитель, пассажир и диван в салоне;
  - его можно толкать всей компанией;
  - топливо, поломки от ударов, ремонт ремкомплектом, канистры;
  - улучшения: двигатель, бак, броня, печка-сушилка.
- **Звуки:** 47 процедурно синтезированных звуков (`tools/gen_sounds.py`). Любой можно заменить
  своим `.wav` с тем же именем в `sounds/`.
- **Перевод:** все строки собраны в `scripts/i18n/ru.gd`. Чтобы добавить язык, скопируйте файл
  и зарегистрируйте его в `scripts/i18n/t.gd`.

## Устройство кода

| Файл | Что делает |
|---|---|
| `scripts/net.gd` | автозагрузка: ENet хост/клиент, раскладка клавиш |
| `scripts/settings.gd` | автозагрузка: настройки и их панель |
| `scripts/sfx.gd` | автозагрузка: загрузка и проигрывание звуков |
| `scripts/world.gd` | корень сцены: спавн сущностей, запросы игроков к хосту, баллистика, погода |
| `scripts/world_builder.gd`, `terrain_gen.gd` | детерминированная генерация мира (одинакова у всех) |
| `scripts/player.gd` | игрок: движение, камера, потребности, инвентарь, оружие, анимации |
| `scripts/animal.gd` | ИИ зверей, хитбоксы зон поражения, кровотечение |
| `scripts/item.gd` | физические предметы (симуляция у хоста) |
| `scripts/rv.gd` | дом на колёсах: КПП, лебёдки, зеркала, повреждения, улучшения |
| `scripts/items_db.gd` | весь баланс: предметы, патроны, оружие, звери, магазин |
| `scripts/hud.gd` | интерфейс и меню |

**Сетевая модель:** у каждого игрока своё движение (клиент-авторитет, синхронизация через
`MultiplayerSynchronizer`). Всё, что меняет общий мир (звери, предметы, дом, деньги, стрельба),
клиент запрашивает у хоста через RPC, а хост проверяет запрос и выполняет его. Сущности
создаёт `MultiplayerSpawner`, поэтому опоздавшие игроки получают текущее состояние мира.

## Сборка exe

В редакторе: Project → Export → Windows Desktop (нужны export templates 4.3). Или без редактора:

```
godot --headless --path . --export-release "Windows Desktop" export/HunterGame.exe
```

При каждом пуше в `main` GitHub Actions собирает exe автоматически (вкладка Actions → артефакт `HunterGame-windows-x64`).

## Тесты без окна

```
godot --headless --path . -s res://tools/smoke_test.gd   # хост: базовые действия
godot --headless --path . -s res://tools/client_test.gd  # клиент к хосту smoke_test
godot --headless --path . -s res://tools/drive_test.gd   # езда на доме
godot --headless --path . -s res://tools/shoot_test.gd   # стрельба всеми калибрами
```

## Ограничения прототипа и следующие шаги

- Графика пока собрана из примитивов и процедурных шейдеров (рельеф, вода, хвоя, трава).
  Дальше: заменить персонажей, зверей и дом на CC0-модели (Quaternius, Kenney, Poly Haven)
  с настоящими скелетными анимациями.
- Незакреплённые предметы в салоне пока не летают при торможении (игроков болтает).
- Нет сохранения прогресса и Steam-лобби.
- Баланс (цены, скорость потребностей, урон) не настраивался по-настоящему, правится в `items_db.gd`.
